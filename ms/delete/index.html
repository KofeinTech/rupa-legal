Padam data anda

Rupa menyimpan sangat sedikit data di awan, dan gambar tidak pernah disimpan pada pelayan Rupa lebih lama daripada 24 jam. Anda masih boleh memadam semua yang kami simpan tentang pemasangan anda pada bila-bila masa. Jika DeviceCheck Apple tidak tersedia buat seketika, kami hanya menyimpan bilangan edit percuma peranti itu (tanpa gambar, tanpa ID aplikasi) sehingga 7 hari sehingga Apple mengesahkannya.

Apa yang disimpan di awan

  • Gambar yang anda hantar ke alat AI awan dan hasilnya, hanya sehingga hasil dimuat turun dan tidak pernah lebih lama daripada 24 jam.
  • ID aplikasi tanpa nama anda dan rekod tetapannya (bahasa, versi aplikasi, tarikh persetujuan, token pemberitahuan).
  • Rekod teknikal ringkas tentang edit awan anda (tanpa gambar) dan bilangan edit anda.
  • Jika anda melanggan: pautan antara ID tanpa nama anda dan langganan Rupa Plus anda.

Edit dan sejarah daripada alat dalam peranti hanya disimpan pada iPhone anda, tidak pernah di awan.

Pilihan 1: dalam aplikasi (paling cepat)

  1. Buka Rupa dan pergi ke Tetapan.
  2. Ketik Padam data awan saya dan sahkan.

Ini serta-merta memadam rekod ID tanpa nama anda, semua rekod edit awan anda, sebarang gambar atau hasil yang masih ada di pelayan kami, dan memutuskan pautan langganan anda daripada pemasangan ini. Gambar dan edit anda pada iPhone tidak terjejas.

Pilihan 2: melalui e-mel

E-mel dimonzalis@gmail.com dengan subjek “Padam data saya”. Rupa tiada akaun, jadi untuk mencari data anda, sila sertakan ID Sokongan yang dipaparkan dalam Tetapan Rupa. Jika anda tidak lagi mempunyai aplikasi tetapi pernah melanggan, sertakan ID pesanan Apple daripada e-mel resit App Store anda. Kami mengesahkan pemadaman dalam masa 15 hari.

Perlu diketahui

  • Langganan anda diteruskan. Memadam data tidak membatalkan Rupa Plus, yang diurus oleh Apple. Untuk membatalkan, pergi ke Tetapan > [nama anda] > Langganan pada iPhone anda. Untuk terus menggunakan Plus selepas memadam data, ketik Pulihkan Pembelian dalam Rupa.
  • Edit percuma tidak diset semula. Bilangan edit awan percuma yang telah digunakan pada iPhone anda disimpan dengan DeviceCheck Apple sebagai dua bit bagi setiap peranti, tanpa sebarang data peribadi, jadi memadam data tidak memberi peranti itu edit percuma baharu. Jika Apple tidak dapat dihubungi pada masa itu, kami hanya menyimpan bilangan tersebut dan token peranti daripada Apple sehingga 7 hari untuk selesai menyimpannya, kemudian memadamnya.
  • Apa yang kami simpan. Rekod yang diperlukan untuk pengebilan, cukai atau undang-undang (contohnya data transaksi Apple bagi langganan) disimpan hanya selama yang diperlukan dan tidak lagi dipautkan kepada ID aplikasi anda. Jumlah tanpa sebarang ID (contohnya bilangan edit sehari) disimpan untuk statistik.
  • Diagnostik. Laporan ranap dan statistik penggunaan tidak dipautkan kepada ID aplikasi anda. Google menyimpannya untuk tempoh terhad di bawah tetapan penyimpanan Firebase.
  • Rakan AI. Padam data awan saya tidak dapat membuang salinan yang disimpan oleh rakan AI kami di bawah terma mereka sendiri, contohnya Google sehingga 55 hari untuk Ubah dengan AI, untuk mencegah penyalahgunaan. Kami belum dapat mengesahkan berapa lama Bria AI menyimpan gambar Buang objek. Lihat Dasar Privasi.
  • Memadam aplikasi membuang semua yang Rupa simpan pada iPhone anda. Gambar di awan tetap dipadam dalam masa 24 jam; untuk membuang yang selebihnya, gunakan Pilihan 1 sebelum memadam aplikasi, atau Pilihan 2.
