Hapus data kamu

Rupa menyimpan sangat sedikit data di cloud, dan foto tidak pernah tersimpan di server Rupa lebih dari 24 jam. Meski begitu, kamu bisa menghapus semua data instalasi kamu yang kami simpan kapan saja. Kalau DeviceCheck Apple sedang tidak bisa dihubungi sebentar, kami hanya menyimpan jumlah edit gratis perangkat itu (tanpa foto, tanpa ID app) paling lama 7 hari sampai Apple mengonfirmasinya.

Apa yang tersimpan di cloud

  • Foto yang kamu kirim ke alat AI cloud beserta hasilnya, hanya sampai hasilnya diunduh dan tidak pernah lebih dari 24 jam.
  • ID app anonim kamu dan catatan pengaturannya (bahasa, versi app, tanggal persetujuan, token push).
  • Catatan teknis singkat dari edit cloud kamu (tanpa foto) dan jumlah edit kamu.
  • Kalau kamu berlangganan: hubungan antara ID anonim kamu dan langganan Rupa Plus.

Edit dan riwayat dari alat di HP hanya tersimpan di iPhone kamu, tidak pernah di cloud.

Cara 1: lewat app (paling cepat)

  1. Buka Rupa, lalu masuk ke Pengaturan.
  2. Ketuk Hapus data cloud saya dan konfirmasi.

Ini langsung menghapus catatan ID anonim kamu, semua catatan edit cloud, foto atau hasil yang masih ada di server kami, dan melepas hubungan langganan dari instalasi ini. Foto dan edit di iPhone kamu tidak terpengaruh.

Cara 2: lewat email

Kirim email ke dimonzalis@gmail.com dengan subjek “Hapus data saya”. Rupa tidak punya akun, jadi supaya data kamu bisa ditemukan, sertakan ID Dukungan yang tampil di Pengaturan Rupa. Kalau app-nya sudah tidak ada tapi kamu pernah berlangganan, sertakan ID pesanan Apple dari email tanda terima App Store. Kami mengonfirmasi penghapusan paling lama dalam 15 hari.

Perlu kamu tahu

  • Langganan tetap berjalan. Menghapus data tidak membatalkan Rupa Plus, karena langganan diatur oleh Apple. Untuk membatalkan, buka Pengaturan > [nama kamu] > Langganan di iPhone. Kalau mau tetap memakai Plus setelah menghapus data, ketuk Pulihkan Pembelian di Rupa.
  • Edit gratis tidak direset. Jumlah edit cloud gratis yang sudah terpakai di iPhone kamu disimpan lewat DeviceCheck Apple sebagai dua bit per perangkat, tanpa data pribadi, jadi menghapus data tidak memberi perangkat itu edit gratis baru. Kalau Apple tidak bisa dihubungi saat itu, kami hanya menyimpan jumlah tersebut dan token perangkat dari Apple paling lama 7 hari untuk menyelesaikan penyimpanannya, lalu keduanya kami hapus.
  • Yang tetap kami simpan. Catatan yang dibutuhkan untuk tagihan, pajak, atau hukum (misalnya data transaksi Apple untuk langganan) hanya disimpan selama diwajibkan dan tidak lagi terhubung dengan ID app kamu. Angka total tanpa ID apa pun (misalnya jumlah edit per hari) disimpan untuk statistik.
  • Diagnostik. Laporan crash dan statistik penggunaan tidak terhubung dengan ID app kamu. Google menyimpannya untuk waktu terbatas sesuai pengaturan retensi Firebase.
  • Mitra AI. Hapus data cloud saya tidak bisa menghapus salinan yang disimpan mitra AI kami berdasarkan ketentuan mereka sendiri, misalnya Google sampai 55 hari untuk Ubah dengan AI, untuk mencegah penyalahgunaan. Kami belum bisa memastikan berapa lama Bria AI menyimpan foto Hapus Objek. Lihat Kebijakan Privasi.
  • Menghapus app menghapus semua yang disimpan Rupa di iPhone kamu. Foto cloud memang otomatis terhapus dalam 24 jam; untuk menghapus sisanya, pakai Cara 1 sebelum menghapus app, atau Cara 2.
